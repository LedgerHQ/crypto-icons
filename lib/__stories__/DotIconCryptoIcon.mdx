# 🔴 DotCryptoIcon

## Introduction

Wraps a `CryptoIcon` with a Lumen `DotIcon` badge to communicate transaction or account status.
The badge overlays a small icon (with a semantic colour) at any corner of the wrapped component.

## Anatomy

<Canvas of={DotIconStories.Base} />

- **`icon` (required)**: A Lumen symbol component (e.g. `Check`, `Clock`, `Close`) rendered inside the badge
- **`appearance` (required)**: Semantic badge colour — `"success"` · `"muted"` · `"error"`
- **`size` (optional)**: Dot diameter — `16 | 20 | 24` (default `20`). Use `{...getDotIconProps('mediaImage', cryptoIconSize)}` so the badge matches the wrapped `CryptoIcon`.
- **`pin` (optional)**: Corner placement — `"bottom-end"` by default
- **`shape` (optional)**: `"circle"` (default) or `"square"`
- **`children`**: The component the badge is attached to (typically `CryptoIcon`)

## Implementation

### 1. Install

```bash
npm install @ledgerhq/crypto-icons
```

### 2. Set up

Set up the Lumen peer dependencies, Tailwind and `ThemeProvider` by following the
[Lumen setup guide](https://lumen-ldls.vercel.app/?path=/docs/getting-started-setup--docs).

### 3. Use

```tsx
import { CryptoIcon } from '@ledgerhq/crypto-icons';
import { DotIcon, getDotIconProps } from '@ledgerhq/lumen-ui-react';
import { Check, Clock, Close } from '@ledgerhq/lumen-ui-react/symbols';
```

### Success (confirmed)

```tsx
<DotIcon icon={Check} appearance="success" {...getDotIconProps('mediaImage', 56)}>
  <CryptoIcon ledgerId="bitcoin" ticker="BTC" size={56} />
</DotIcon>
```

### Muted (pending)

```tsx
<DotIcon icon={Clock} appearance="muted" {...getDotIconProps('mediaImage', 56)}>
  <CryptoIcon ledgerId="bitcoin" ticker="BTC" size={56} />
</DotIcon>
```

### Error (failed)

```tsx
<DotIcon icon={Close} appearance="error" {...getDotIconProps('mediaImage', 56)} pin="top-end">
  <CryptoIcon ledgerId="bitcoin" ticker="BTC" size={56} />
</DotIcon>
```
